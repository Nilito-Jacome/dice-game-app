# Dice Game App 🎲

Aplicación en línea con:
- Frontend: React (Netlify)
- Backend: Node.js/Express (Render/Railway)
- IA: FastAPI + TensorFlow (Render/Railway)
- Base de datos: MongoDB Atlas

## 🚀 Instalación local
1. Clonar repo: `git clone https://github.com/TU_USUARIO/dice-game-app`
2. Backend:
   - `cd backend`
   - `npm install`
   - `MONGODB_URI=tu_uri node index.js`
3. IA:
   - `cd ai`
   - `pip install fastapi uvicorn tensorflow numpy`
   - `uvicorn app:app --reload --port 8000`
4. Frontend:
   - `cd frontend`
   - `npm install`
   - `npm start`

## 🌐 Despliegue
- Frontend → Netlify
- Backend → Render/Railway
- IA → Render/Railway
- Base de datos → MongoDB Atlas
